# Xanthomonas 3-Proteome Project

This project compares three annotated Xanthomonas proteomes:

- pomegranate
- citrus
- grape

## Goal
Identify virulence signatures linked to host specificity.

## Input
Place FASTA files:
- data/raw/pomegranate/proteins.faa
- data/raw/citrus/proteins.faa
- data/raw/grape/proteins.faa
